# Azure + Python Upskilling

My hands-on journey from **OFSAA / data-modeling consultant** to **building real applications on Azure with Python**. Starting from zero programming, I'm building a web app, a data engineering pipeline and a DevOps setup, then joining them into one portfolio project.

The day-by-day plan lives in **[`azure_apps_6week_plan.md`](./azure_apps_6week_plan.md)**.

## Goals
- Write, test and debug Python confidently, starting from zero.
- Build and deploy a **web app** on Azure (Flask, App Service, Azure SQL, Key Vault, Entra ID).
- Build a **data engineering pipeline** (ADLS Gen2, Data Factory, Databricks/PySpark, Power BI).
- Automate it all with **DevOps** (Azure DevOps pipelines, Bicep, containers).
- Ship a documented **capstone** I can demo in interviews.
- Retake and pass **AZ-900** with real hands-on understanding behind it.
