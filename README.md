# Azure + Python Upskilling

My 4-week, hands-on journey from **OFSAA / data-modeling consultant** to **cloud + Python for data**. Azure Fundamentals (AZ-900) first, then Python with a data focus, ending in a small Python + Azure data pipeline.

This repo holds my code, notes, and exercises for the plan. The full day-by-day schedule lives in **[`azure_python_4week_plan.md`](./azure_python_4week_plan.md)**.

## Goals
- Pass **AZ-900** — with real ability to *apply* concepts to scenarios, not just recall them.
- Learn **Python** well enough to ingest, clean, join, analyze, and store real datasets.
- Ship a documented **capstone pipeline** combining Python + Azure.

## Working with Claude Code
1. Open this folder in your terminal/IDE and run `claude`.
2. It reads `CLAUDE.md` automatically, so it already knows my background, how I like to learn, and my weak spots.
3. Start a session with something like:
   *"We're starting Week 2, Day 1. Walk me through it per the plan — concept first, then let me write the code."*
