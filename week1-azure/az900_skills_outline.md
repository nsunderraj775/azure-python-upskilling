# AZ-900 — Skills Measured (study checklist)

> **Source:** [Official Microsoft Learn study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-900)
> **Version:** Skills measured *as of July 20, 2026* (the 2026 update is logged as **Minor** — small tweaks only).
> **Pass mark:** 700/1000. **Free practice assessment:** linked from the study-guide page.
>
> Tick each box as you can *explain it aloud AND apply it to a scenario* (not just recall the definition — your known weak spot).

---

## 1. Describe cloud concepts (25–30%)

### Describe cloud computing
- [ ] Define cloud computing
- [ ] Describe the **shared responsibility model**
- [ ] Define cloud models: public, private, hybrid
- [ ] Identify appropriate **use cases** for each cloud model
- [ ] Describe the consumption-based model
- [ ] Compare cloud pricing models
- [ ] Describe serverless

### Describe the benefits of using cloud services
- [ ] High availability and scalability
- [ ] Reliability and predictability
- [ ] Security and governance
- [ ] Manageability

### Describe cloud service types
- [ ] IaaS
- [ ] PaaS
- [ ] SaaS
- [ ] Identify appropriate **use cases** for each (IaaS / PaaS / SaaS)

---

## 2. Describe Azure architecture and services (35–40%)

### Core architectural components
- [ ] Regions, region pairs, sovereign regions
- [ ] Availability zones
- [ ] Azure datacenters
- [ ] Resources and resource groups
- [ ] Subscriptions
- [ ] Management groups
- [ ] The hierarchy: resource groups → subscriptions → management groups

### Compute and networking services
- [ ] Compare compute types: containers, VMs, functions
- [ ] VM options: Azure VMs, VM Scale Sets, availability sets, Azure Virtual Desktop
- [ ] Resources required for VMs
- [ ] Application hosting options: web apps, containers, VMs
- [ ] Virtual networking: VNets, subnets, peering, Azure DNS, VPN Gateway, ExpressRoute
- [ ] Public vs private endpoints

### Storage services
- [ ] Compare Azure Storage services
- [ ] Storage tiers (hot / cool / archive)
- [ ] Redundancy options (LRS / ZRS / GRS / GZRS)
- [ ] Storage account options and storage types
- [ ] Moving files: AzCopy, Azure Storage Explorer, Azure File Sync
- [ ] Migration: Azure Migrate, Azure Data Box

### Identity, access, and security
- [ ] Directory services: Microsoft Entra ID, Entra Domain Services
- [ ] Authentication methods: SSO, MFA, passwordless
- [ ] External identities
- [ ] Microsoft Entra Conditional Access
- [ ] Azure role-based access control (RBAC)
- [ ] Zero Trust
- [ ] Defense-in-depth model
- [ ] Microsoft Defender for Cloud
